# IDC 云主机 + DNS 域名分发系统 安装说明

这套系统用 ThinkPHP 5.1 开发，**PHP 7.0 就能跑**（7.0 – 8.x 都支持）。它能放在宝塔面板、普通 PHP 虚拟主机、Windows IIS 上，不需要 Docker，不需要命令行，也不需要把任何目录设成 777。

安装方式很简单：把压缩包解压到网站根目录，再用浏览器打开安装向导，按提示填就行。

---

## 一、准备工作

| 项目 | 要求 |
|---|---|
| PHP | 7.0 或更高（推荐 7.4 / 8.1） |
| 必需扩展 | pdo_mysql、curl、openssl、json（绝大多数主机默认都开着） |
| 可选扩展 | mbstring（没有也能用，系统自带兼容处理）、gd（不需要，验证码是 SVG） |
| 数据库 | MySQL 5.6+ 或 MariaDB 10.0+，字符集 utf8mb4 |
| Web 服务器 | Nginx / Apache / LiteSpeed / IIS 都可以；**没有伪静态也能用** |
| 不需要 | Docker、exec/shell_exec 等函数、常驻进程、Redis、命令行 |

先在主机面板里建一个**空数据库**，记下数据库名、用户名、密码。

---

## 二、上传和解压

1. 把安装包 `o2o-idc-dns-1.0.0.zip` 上传到网站根目录（比如宝塔的 `/www/wwwroot/你的域名/`，虚拟主机通常是 `htdocs`、`public_html` 或 `wwwroot`）。
2. 直接在根目录解压。解压后根目录里应该**直接**看到这些：

```
index.php      ← 网站入口
install.php    ← 安装向导（装完会自动锁定）
cron.php       ← 命令行计划任务入口（只能命令行运行）
.htaccess      ← Apache/虚拟主机规则
web.config     ← IIS 规则
core/          ← 程序代码（已禁止网页访问）
data/          ← 数据目录（已禁止网页访问）
static/        ← CSS/JS/图片（含内置 o2o云 Logo 和网站图标）
uploads/       ← 后台上传的 Logo/图标（已禁止在这里运行脚本）
favicon.ico    ← 浏览器标签页图标
INSTALL.md     ← 本说明（可删除）
```

> 如果解压后多了一层文件夹（例如 `idcdns/index.php`），把里面的文件移到根目录即可。也可以装在子目录里，比如 `https://域名/idc/`，系统会自动识别。

3. 权限：`data/` 目录需要对 PHP 运行用户**可写**（宝塔：所有者设为 `www`，权限 755 即可；IIS：给 `IIS_IUSRS` "修改"权限）。如果要在后台上传自己的 Logo，`uploads/brand/` 也要可写。其他目录只读即可。**不要设 777。**

---

## 三、浏览器安装向导

打开 `https://你的域名/install.php`：

1. **环境检测**：红色项必须先处理（通常是缺扩展或 data 目录不可写），HTTPS 和 mbstring 只是建议。
2. **数据库**：填主机（一般 `127.0.0.1` 或 `localhost`）、端口 3306、库名、用户名、密码、表前缀（默认 `idc_`）。
3. **站点信息**：站点名称、网站地址（自动识别，子目录安装会带上子目录）。
4. **管理员**：用户名、邮箱、密码（两次）。
5. **数据目录**（重要，三选一）：
   - **网站内随机名目录**（默认、推荐）：自动建一个 `data_8f3a…` 这样的随机名目录存放配置、缓存、日志。即使主机不支持 `.htaccess`，别人也猜不到路径。
   - **自定义绝对路径**：放到网站根目录以外最安全，比如 `/www/idc_data` 或 `D:/idc_data`。主机开了 open_basedir 的话，路径要在允许范围内。
   - **网站根目录下的 data**：依赖 `.htaccess` / `web.config` / Nginx 规则来保护，只建议在你确定规则生效时用。
6. 点"开始安装"。完成页会显示**后台地址**和**计划任务地址**，请保存。

安装完成后 `install.php` 会自动锁定，重复访问只会提示"已安装"。为了安全，建议再把它删掉或改名。

后台地址：`https://你的域名/index.php?s=/admin`（开了伪静态也可以用 `https://你的域名/admin`）。

## 四、按环境的额外设置

### 宝塔面板（Nginx）

网站 → 设置 → **伪静态**，粘贴 `core/install/nginx.conf.example` 里的规则并保存。它做了三件事：开启漂亮网址；禁止访问 `core`、`data`、`data_随机名`；禁止在 `uploads/` 里运行 PHP。

不配伪静态也能用，网址会是 `index.php?s=/...` 这种形式。

### 宝塔面板（Apache） / 普通虚拟主机（Apache、LiteSpeed）

不用额外设置。根目录的 `.htaccess` 会开启伪静态，`core/`、`data/` 里也各自放了禁止访问的规则，`uploads/` 里的规则会禁止运行脚本。

如果主机**不支持 .htaccess**（AllowOverride None），也没关系：
- 网址自动用 `index.php?s=/...` 兼容模式；
- 数据目录用了随机名（或你选的网站外路径），而且里面的配置文件都是 PHP 格式，直接访问只会得到空白页，不会泄露内容。

### Windows / IIS

1. 在 IIS 里为网站选择 PHP 7.0+（FastCGI）。
2. 根目录的 `web.config` 已经禁止访问 `core`、`data`，安装器也会在数据目录里写入单独的 `web.config` 拒绝所有文件。
3. 如果装了 **IIS URL Rewrite** 模块，打开 `web.config`，把注释里的 `<rewrite>` 规则取消注释即可开启伪静态；没装也能用兼容网址。
4. 给 `data` 目录（或你自定义的数据目录）添加 `IIS_IUSRS` 的"修改"权限。

## 五、计划任务（到期提醒、自动暂停、发通知等都靠它）

建议**每 5 分钟**执行一次。以下方式选**一种**即可：

**方式 1：宝塔 / Linux 命令行**

宝塔 → 计划任务 → Shell 脚本，每 5 分钟：

```
php /www/wwwroot/你的域名/cron.php
```

**方式 2：访问网址（虚拟主机首选，不需要命令行）**

后台 → 系统设置 → 计划任务里可以复制这个地址（带密钥）：

```
https://你的域名/index.php?s=/api/cron/run&key=你的密钥
```

把它填到：主机面板的"定时访问 URL / 计划任务-访问网址"，或者 [cron-job.org](https://cron-job.org)、UptimeRobot 这类免费外部监控，每 5 分钟访问一次。

它的行为：
- 密钥错了返回 HTTP 403，正在运行返回 409，所以监控能看出异常；
- 同一时间只跑一个（文件锁）；
- 每次最多跑 25 秒（可在后台改），没做完的下次接着做，适合限制执行时间的虚拟主机；
- 通知队列（邮件/Telegram）每次都优先发送。

密钥泄露了可以在后台点"重新生成密钥"。

**方式 3：访问触发（兜底，默认关闭）**

如果主机连"定时访问网址"都没有，也不想用外部监控，可以在后台打开"访问触发"：有人访问前台时，在页面发给访客之后顺带跑一小批任务（最多 5 秒，默认至少隔 300 秒一次）。访问量少的时候任务会延迟，所以只是兜底方案。

**Windows**：任务计划程序里每 5 分钟运行 `php.exe D:\网站目录\cron.php`，或者用方式 2。

## 六、装完后在后台要设置的东西

所有配置都在后台改，不需要改代码。建议按这个顺序：

1. **系统设置**：站点名称、货币符号、网址模式、注册开关、验证码、风控。
   - **Logo 和网站图标**（系统设置 → 基本）：默认用内置的 o2o云 Logo 和蓝色方块图标。可以分别上传「Logo」（浅色背景用，前台页头和邮件）、「深色背景 Logo」（后台侧栏用，不传就用普通 Logo）、「网站图标」（.ico 或 .png，最大 256KB）。Logo 支持 PNG/JPG/GIF/WebP，最大 1MB；出于安全不接受 SVG。上传的文件会改成随机文件名保存；勾选「恢复默认」并保存就会删除上传的文件、回到内置图片。
2. **通知**：SMTP 邮箱（Brevo、QQ、163、Gmail 有预设）、Telegram 机器人 Token 和管理员 chat ID，各类通知模板。保存后在 SMTP / Telegram 标签页底部可以直接发测试邮件、测试消息。邮件默认使用带 Logo 的品牌 HTML 模板（同时附纯文本版本），不想要可以关掉「邮件使用品牌 HTML 模板」开关。
3. **支付网关**（共 5 种）：余额支付、易支付（兼容彩虹易支付协议）、BEpusdt（USDT）、支付宝官方（RSA2）、线下人工确认。填好商户信息后启用，回调地址在网关页面里可以直接复制。
4. **上游接口**：
   - **WHMCS**：接口地址填 WHMCS 根地址（例如 `https://whmcs.example.com`），填 API Identifier / Secret（WHMCS 后台 → 系统设置 → API 凭据创建），如有访问限制再填 Access Key，并把本站服务器 IP 加入 WHMCS 的 API IP 白名单。可设置统一上游客户 ID 或按邮箱自动创建客户、支付方式、币种、续费模式。
   - **智简魔方 V10 业务系统**：接口地址、API 用户名、API Token，接口前缀默认 `/api/v1`。
   - **魔方财务（旧版）**：接口地址、用户名、API 密码，接口前缀默认 `/api`。
   - **NAT 小鸡节点**（自建 Incus/LXD）：后台生成一键安装命令，到节点服务器执行后自动注册。
   - 每个上游都有"测试连接"按钮，可以导入上游商品。
5. **产品与分组**：云主机产品绑定上游商品，设置价格周期、库存、每人限购、低库存提醒。
6. **DNS 服务商**（14 家）：腾讯云 DNSPod、阿里云、Cloudflare、华为云、百度智能云、西部数码、火山引擎、京东云、DNS.LA、NameSilo、GoDaddy、PowerDNS、DigitalOcean、Spaceship。填好密钥后"测试连接"，再添加可分发的主域名。
7. **会员等级、DNS 套餐、优惠码、卡密**：按需设置。
8. **域名市场**：开关、佣金比例、审核、提现方式、优惠码由谁承担。

## 七、两步验证（谷歌验证器）和找回密码

**管理员开启两步验证（强烈建议）**：登录后台 → 右上角或「系统 → 我的两步验证」→ 用 Google Authenticator、Microsoft Authenticator、Authy 等 App 扫描页面上的二维码（也可以手动输入下面的密钥）→ 输入 App 里的 6 位数字和登录密码 → 开启。开启后页面会显示 **10 个恢复码，只显示这一次**，请下载或抄下来放在安全的地方；手机丢了可以用恢复码登录，每个只能用一次，用完可以重新生成。二维码在本站服务器上生成，不会把密钥发给任何外部网站。

开启后：
- 登录时输完密码还要输 App 里的 6 位验证码（或一个恢复码）；同一个验证码不能用两次；连续输错 5 次锁定 15 分钟。
- 修改支付网关、DNS 服务商、上游接口、NAT 节点、系统设置、管理员、用户资料，审批提现时，如果离上次输入验证码超过设定时长（默认 5 分钟），会先要求再输一次验证码。
- 大额余额调整（默认 1000 以上，可在设置里改）要同时输入登录密码和谷歌验证码。
- 开启、关闭、重置两步验证和修改密码都会发邮件提醒并写入审计日志。

**后台设置**（系统设置 → 登录安全，只有超级管理员能看到）：是否强制所有管理员开启两步验证（开启后没绑定的管理员登录会被带到绑定页，绑定前不能用后台其他功能）、敏感操作免验证时长、App 里显示的名称、找回密码方式（邮箱验证码 / 邮件链接 / 两种都行）和有效期、大额调整金额。

**普通用户**：用户中心 →「账号安全」，开启方式与后台相同。

**找回密码**：后台登录页和前台登录页都有「忘记密码」。输入注册邮箱后会收到验证码或一次性链接（为了不暴露哪些邮箱注册过，邮箱不存在时提示也一样）。**开启了两步验证的账号，找回密码时还必须输入谷歌验证码或恢复码**，只拿到邮箱也改不了密码。改完密码后，这个账号在其他地方的登录会自动退出。同一邮箱 60 秒内只能发一次、每小时最多 5 次。找回密码依赖 SMTP，请先在通知设置里配好并发一封测试邮件。

**手机丢了、恢复码也没了怎么办？**
- 其他超级管理员可以在「系统 → 管理员」列表里点「重置两步验证」；用户的两步验证可以在后台用户列表里重置。
- 只有一个管理员时，用服务器命令行（SSH 或宝塔终端，在网站根目录执行，网页无法访问这个工具）：

```bash
php core/tools/admin_reset.php list                 # 查看管理员和两步验证状态
php core/tools/admin_reset.php reset-2fa admin      # 关闭 admin 的两步验证
php core/tools/admin_reset.php unlock admin         # 解除输错次数过多的锁定
php core/tools/admin_reset.php reset-password admin # 生成一个随机新密码（只显示一次）
```

宝塔里 PHP 命令可能是 `/www/server/php/70/bin/php`（70 换成你网站用的版本）。这些操作同样写入审计日志并发邮件提醒。

## 八、安全自查（装完花 1 分钟）

用浏览器访问下面这些地址，**都不应该看到任何内容**（403、404 或空白页都对）：

- `https://你的域名/data/config.php`
- `https://你的域名/core/install/schema.sql.php`
- `https://你的域名/core/application/common.php`
- `https://你的域名/uploads/brand/` 下放一个 `test.php` 再访问，不应该被执行（看到 403 或源码下载提示都说明规则生效，检查完记得删掉）

然后：
- 确认 `install.php` 已删除或访问提示"已安装"；
- 后台改一个强密码（至少 8 位，包含字母和数字，不能和用户名/邮箱相同），开启登录验证码，并给每个管理员开启两步验证；
- `https://你的域名/core/tools/admin_reset.php` 也应该打不开（这个工具只能在命令行用）；
- 计划任务地址不要公开分享。

## 九、常见问题

**页面 404 / 网址打不开？** 没配伪静态时请用 `index.php?s=/...` 形式的网址；后台"网址模式"设为"兼容模式"。

**提示 data 目录不可写？** 宝塔把网站目录所有者改为 `www`；虚拟主机在文件管理里给 data 目录写权限（755 一般就够）；IIS 给 `IIS_IUSRS` 修改权限。

**开了 open_basedir（宝塔"防跨站攻击"）报错？** 1.0.0 正式包已兼容宝塔默认的防跨站设置，不用关闭它。数据目录选"网站内随机名目录"最省事；用自定义数据目录时，要放在 open_basedir 允许的范围内。

**图形验证码不显示？** 不需要安装任何 PHP 扩展（验证码是 SVG 图片，不依赖 GD）。请确认用的是最新安装包；如果前面加了 CDN（如 Cloudflare），不要对 `index.php?s=/index/auth/captcha` 开缓存。直接在浏览器打开 `你的域名/index.php?s=/index/auth/captcha&scene=register`，正常时会看到一张验证码图片，而不是一串代码。

**通知不发？** 检查计划任务有没有在跑（后台「系统设置 → 计划任务」能看到最近运行时间和结果），再检查 SMTP/Telegram 设置并发测试消息。Telegram 的 Bot Token 保存后输入框会显示"已保存，留空不修改"，再次保存时留空不会清掉它；测试消息默认发给"管理员 Chat ID"。

**换了 Logo 但浏览器标签页还是旧图标？** 浏览器会缓存网站图标，强制刷新（Ctrl+F5）或过一会儿再看。

**谷歌验证码总是提示错误？** 验证码按时间计算，服务器和手机时间要准。手机打开「自动设置时间」；服务器执行 `date` 看时间是否正确（宝塔可以在「面板设置」里同步时间）。允许前后各差 30 秒。

**收不到找回密码邮件？** 先在后台发一封测试邮件；看看垃圾箱；同一邮箱 60 秒内只能发一次。实在收不到，管理员可以用上面的命令行工具重置密码。

**升级或迁移？** 备份数据库和数据目录（`data/`、`data_随机名/` 或你的自定义路径），把新版文件覆盖到根目录即可，不要覆盖数据目录。新版本需要的数据库字段会在下一次打开后台或计划任务运行时自动补上。
